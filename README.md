# My Personal Website

This repository contains the files for my personal website, hosted for free using GitHub Pages.

## How to host this website on GitHub

Follow these steps to get your own version of this website up and running.

### 1. Create a new repository on GitHub

*   Go to [https://github.com/new](https://github.com/new).
*   For the "Repository name", you **must** use `<your-github-username>.github.io`. For example, if your username is `bastv`, you must name the repository `bastv.github.io`. This is very important for GitHub Pages to work.
*   Make sure the repository is set to **Public**.
*   You can leave the other options as they are.
*   Click "Create repository".

### 2. Upload the `index.html` file

After you create the repository, you need to upload the `index.html` file from this project.

*   In your new repository on GitHub, click the "Add file" button and then "Upload files".
*   Drag and drop the `index.html` file into the upload area.
*   Click the "Commit changes" button.

### 3. Your website is live!

After you commit the file, GitHub Pages will automatically build and deploy your site. It should be available at `https://<your-github-username>.github.io` (e.g., `https://bastv.github.io`) within a few minutes.
